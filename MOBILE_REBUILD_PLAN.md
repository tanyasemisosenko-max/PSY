# Mobile Rebuild Plan

Project: Примерочная себя
Branch: mobile-rebuild
Desktop: frozen, do not touch
Approach: mobile is a separate vertical version, not a scaled desktop

## Goal

Rebuild the mobile version as a separate vertical user flow while keeping the same meaning, style, content, forms and conversion goal.

## Work principle

One screen at a time:

- rebuild screen;
- check on 360 / 375 / 390 / 414 / 430px;
- confirm no desktop changes;
- only then move to the next screen.
